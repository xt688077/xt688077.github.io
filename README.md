# 个人简历网站公开版

这是一个适合上传 GitHub Pages 的公开版个人简历网站，已对联系方式、头像、截图和原始简历文件做脱敏处理。

**在线预览：** [xt688077.github.io](https://xt688077.github.io/)

项目采用原生 HTML、CSS 和 JavaScript 构建，无需安装依赖即可部署。

## 🚀 快速部署（GitHub Pages）

1. **Fork 本仓库** 到您的 GitHub 账户。
2. 将仓库重命名为 `你的用户名.github.io`。
3. 进入仓库的 **Settings → Pages**，将分支改为 `main` 并保存。
4. 等待几分钟，即可通过 `https://你的用户名.github.io` 访问您的简历站。

## ✏️ 自定义修改建议

- **个人信息**：编辑 `index.html` 中的姓名、学校、简介、联系方式等文本内容。
- **作品案例**：修改 `zpj.html` 中的卡片标题、描述、链接，替换为您的实际项目。
- **商城演示**：`网站1.html` 为独立页面，若不需要可删除或替换为其他项目。
- **样式调整**：若对颜色、字体、间距不满意，可修改 `styles.css` 中的 CSS 变量（`:root` 部分）。
- **删除非必要文件**：`track-visitors.js`（如存在）应删除，以免向他人数据库发送数据；`CNAME` 文件若未绑定域名也需删除。

## 📌 注意事项

- 本简历为**公开版**，已脱敏处理（联系方式、头像、截图等均已替换或隐藏）。
- 所有页面均支持**深色/浅色主题**切换，通过右上角的月亮/太阳按钮控制，并会记住用户偏好。
- 响应式设计适配手机、平板和桌面设备。
